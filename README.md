IPL Analytics Project

Project Overview

This project analyzes Indian Premier League (IPL) data to identify team performance trends, player statistics, and match outcomes.

Objectives

- Analyze IPL match data.
- Identify team and player performance trends.
- Visualize key insights using charts.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

Dataset

IPL dataset used for analyzing match results, teams, players, and performance statistics.
 
Key Insights:
Anchor Batter – Suryakumar Yadav (MI):-
Suryakumar Yadav recorded an impressive batting average of 65.18 and scored 717 runs in 16 innings. His performance makes him a strong candidate for the anchor role, combining consistent run production with the ability to maintain the innings.

Power Hitter – Vaibhav Suryavanshi (RR):-
Vaibhav Suryavanshi achieved a strike rate of 206.55 and a boundary percentage of 85.71%, based on the provided dataset. This indicates an aggressive scoring style and makes him a strong candidate for a power-hitting role.

Best of Both – Suryakumar Yadav (MI):-
Suryakumar Yadav combines a batting average of 65.18 with a strike rate of 167.91. This suggests he can contribute both consistency and scoring speed, making him a valuable all-round batting option.

Data-Driven Player Selection:-
Filtering players by minimum innings or balls faced helps reduce the influence of very small samples. The analysis can support franchise decision-making by identifying batters suited to stability, aggressive scoring, and balanced performance.
